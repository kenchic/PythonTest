# PythonTest

## Descripción
Este repositorio está diseñado para almacenar ejercicios y pruebas realizadas durante el curso de Python. Aquí encontrarás diferentes ejemplos y prácticas que ayudarán en el aprendizaje del lenguaje.

## Estructura del Proyecto
- `src/`: Directorio principal para el código fuente
- `docker/`: Directorio para archivos relacionados con la containerización

## Objetivo
El objetivo principal de este repositorio es servir como espacio de práctica y experimentación para mejorar las habilidades en Python.
